# โพลคุณโทนี่

เว็บโพลที่ใครมีลิงก์ก็โหวตได้ ไม่ต้องล็อกอิน ผลรวมไม่แสดงชื่อใคร

โครงสร้าง

- `public/index.html` หน้าโพล
- `api/poll.js` ฟังก์ชันรับโหวตและส่งผลรวม เก็บข้อมูลใน Redis

## วิธีขึ้น Vercel (ฟรี)

1. สมัคร Vercel ที่ vercel.com (ใช้บัญชี GitHub หรืออีเมลก็ได้)
2. เอาโฟลเดอร์นี้ขึ้นเว็บ ทำอย่างใดอย่างหนึ่ง
   - อัปโหลดโฟลเดอร์ขึ้น GitHub แล้วกด Add New > Project ใน Vercel เลือก repo นั้น
   - หรือเปิดเทอร์มินัลในโฟลเดอร์นี้ แล้วรัน `npx vercel`
3. Framework Preset เลือก Other ช่อง Build Command กับ Output Directory ปล่อยว่าง
4. เปิดโปรเจกต์ใน Vercel ไปแท็บ Storage กด Create Database เลือก Upstash Redis แพ็กเกจฟรี แล้วกด Connect ให้โปรเจกต์นี้ Vercel จะเพิ่ม environment variables ให้เอง
5. กด Redeploy หนึ่งครั้งให้ตัวแปรมีผล
6. เปิดลิงก์ `https://ชื่อโปรเจกต์.vercel.app` ลองโหวตเอง แล้วส่งลิงก์ให้คนอื่น

โค้ดอ่านตัวแปร `UPSTASH_REDIS_REST_URL` และ `UPSTASH_REDIS_REST_TOKEN` ถ้าไม่มีจะลอง `KV_REST_API_URL` และ `KV_REST_API_TOKEN` แทน ตัวแปรชุดไหนก็ได้ที่ Vercel ใส่ให้

## ความเป็นนิรนาม

เบราว์เซอร์สร้างรหัสสุ่มเก็บไว้ในเครื่อง ฝั่งเซิร์ฟเวอร์เก็บแค่ค่าแฮชของรหัสนั้นไว้กันนับซ้ำ ไม่เก็บชื่อ อีเมล หรือ IP และ API ส่งกลับแค่ผลรวม

เปิดด้วยหน้าต่างไม่ระบุตัวตน หรือเปลี่ยนเบราว์เซอร์ จะโหวตซ้ำได้ ถ้าโพลนี้ต้องแม่นยำจริงจัง ต้องเพิ่มระบบอื่นเข้ามา

## เริ่มโพลใหม่

เข้าหน้า Storage ของฐานข้อมูลใน Vercel เปิด Data Browser แล้วลบคีย์ `tony-poll:votes`
